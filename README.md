# ScreenSnip

Маленькая утилита для Windows: по горячей клавише замораживает экран, даёт выделить
прямоугольную область и кладёт её в буфер обмена. Ничего больше.

- ✅ Настраиваемая горячая клавиша (через окно настройки или файл конфигурации)
- ✅ Заморозка экрана на время выделения
- ✅ Прямоугольное выделение мышью, область вне выделения затемняется
- ✅ Отмена по `Esc` или правой кнопкой мыши
- ✅ Поддержка нескольких мониторов (при одинаковом масштабе DPI)
- ✅ Автозапуск при входе в Windows
- ✅ Иконка в системном трее
- ❌ В файл ничего не сохраняется — только буфер обмена

## Использование

После запуска программа висит в трее. Нажмите хоткей (по умолчанию **Ctrl+Shift+S**):

1. Экран «замораживается» и затемняется.
2. Зажмите левую кнопку мыши и выделите прямоугольник (можно тянуть через несколько мониторов).
3. Отпустите кнопку — выделенная область скопирована в буфер обмена.
4. `Esc` или правый клик — отмена.

## Изменение горячей клавиши

Самый простой способ — **левый клик по иконке в трее** (или правый клик →
«Изменить хоткей…»). Откроется маленькое окно:

1. Нажмите нужную комбинацию (например, `Ctrl` + `Shift` + `A`). В заголовке окна
   видно, какие модификаторы уже зажаты.
2. Как только нажмёте основную клавишу — комбинация **сразу** применяется
   (без перезапуска) и сохраняется в конфиг.
3. `Esc` — отмена. Если комбинация уже занята системой/другой программой —
   об этом сообщит заголовок окна, останется прежняя.

## Конфигурация

Файл можно править и вручную; создаётся автоматически при первом запуске:

```
%APPDATA%\ScreenSnip\ScreenSnip\config.toml
```

```toml
hotkey = "Ctrl+Shift+S"
autostart = true
```

- **hotkey** — модификаторы `Ctrl`/`Shift`/`Alt`/`Win` через `+`, затем клавиша.
  Примеры: `"Ctrl+Shift+S"`, `"Alt+PrintScreen"`, `"Ctrl+F8"`, `"Win+Shift+A"`.
  Клавишей может быть буква/цифра, `F1`..`F24` или имя (`PrintScreen`, `Insert`, `Home`…).
- **autostart** — добавлять/убирать программу из автозапуска (ветка реестра `HKCU\…\Run`).

При смене хоткея через окно настройки изменения применяются сразу. При ручной
правке файла — после перезапуска программы (пункт «Выход» в трее → запустить снова).
Пункт меню в трее «Открыть конфиг» откроет этот файл.

> ⚠️ Не используйте `Win+Shift+S` — это встроенный «Ножницы» Windows, он перехватит хоткей.

## Обновление до новой версии

**Если ставили через установщик:**

1. Соберите новую версию: `cargo build --release`.
2. В `installer\setup.iss` увеличьте `MyAppVersion` (например, `0.1.0` → `0.2.0`).
   **`AppId` менять нельзя** — именно по нему Inno распознаёт уже установленную программу.
3. Соберите установщик и запустите новый `ScreenSnip-Setup-X.Y.Z.exe`.

Установщик увидит установленную версию (по `AppId`) и обновит её **на месте**. Если
программа запущена, по `AppMutex` он предложит её закрыть. Конфиг и автозапуск
сохраняются — отдельно удалять старую версию не нужно.

**Если запускаете portable (просто exe):** «Выход» в трее → замените файл на новый → запустите.

## Удаление

**Установленную через установщик** программу удаляют как обычно:

- **Параметры Windows → Приложения → ScreenSnip → Удалить**, либо
- ярлык **«Удалить ScreenSnip»** в меню «Пуск».

Деинсталлятор закроет программу, удалит файлы **и запись автозапуска** из реестра.
Файл конфигурации (`%APPDATA%\ScreenSnip\…`) остаётся — удалите вручную при желании.

**Portable-версию** удаляют так: «Выход» в трее, удалить exe, а чтобы убрать
автозапуск — выставить `autostart = false` в конфиге и один раз запустить (программа
сама снимет запись), либо удалить значение реестра вручную:

```powershell
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v ScreenSnip /f
```

## Сборка (на машине с Windows)

Все зависимости используют Windows-бэкенды (захват экрана, трей, окна), поэтому
**собирать нужно на Windows** — кросс-компиляция из Linux не поддерживается.

### 1. Установить Rust

Скачайте и запустите `rustup-init.exe` с https://rustup.rs и пройдите установку
(вариант по умолчанию — стабильный тулчейн `x86_64-pc-windows-msvc`).

Rust на Windows требует компоновщик MSVC. Если установка `rustup` попросит —
поставьте **Visual Studio Build Tools** с компонентом «Разработка классических
приложений на C++» (включает MSVC и Windows SDK). Ссылка:
https://visualstudio.microsoft.com/visual-cpp-build-tools/

Проверка:

```powershell
rustc --version
cargo --version
```

### 2. Собрать релизный бинарник

В папке проекта:

```powershell
cargo build --release
```

Готовый файл: `target\release\screensnip.exe` (один самодостаточный exe).

Запустить прямо так:

```powershell
.\target\release\screensnip.exe
```

### 3. (Опционально) Собрать установщик .exe

Есть два варианта установщика. **NSIS** собирается даже из Linux, **Inno Setup** — только на Windows.

**Вариант A — NSIS (`installer/screensnip.nsi`), собирается из Linux:**

```bash
sudo apt-get install -y nsis      # один раз
# сначала соберите релизный exe и положите его в dist/screensnip.exe
makensis -DSRCEXE=$PWD/dist/screensnip.exe \
         -DOUTFILE=$PWD/dist/ScreenSnip-Setup-0.1.0.exe \
         installer/screensnip.nsi
```

Готовый `dist/ScreenSnip-Setup-0.1.0.exe` ставит программу в `Program Files\ScreenSnip`,
создаёт ярлыки в «Пуске», заводит запись в «Установка и удаление программ». Удаление
(оттуда же или ярлыком «Удалить ScreenSnip») закрывает программу, удаляет файлы,
ярлыки **и запись автозапуска** из реестра.

**Вариант B — Inno Setup (`installer/setup.iss`), на Windows:**

1. Установите **Inno Setup**: https://jrsoftware.org/isdl.php
2. Соберите релиз (`cargo build --release`).
3. `ISCC installer\setup.iss` (или Compile в GUI) → `installer\output\ScreenSnip-Setup-0.1.0.exe`.

Оба установщика кладут программу в `Program Files\ScreenSnip`. Автозапуск включает
само приложение (по настройке `autostart` в конфиге).

## Замечания

- **DPI.** Код рассчитан на одинаковый масштаб на всех мониторах. При смешанном
  масштабе (например, ноутбук 150% + внешний 100%) выделение на втором мониторе
  может смещаться — это потребует отдельной схемы «окно на каждый монитор».
- **Заморозка.** Скриншот делается ДО показа оверлея, поэтому на экране именно
  замороженный кадр, а не живое изображение.
- **Антивирус.** Глобальный хоткей + автозапуск + работа с буфером иногда вызывают
  ложные срабатывания эвристик. Бинарник без подписи; при необходимости подпишите.
